# Grassland scenic art source

`grassland_far.png` is a carefully cropped painterly parallax fragment from a newly generated TATO! style illustration. The crop omits HUD, character, terrain, and most gameplay objects; it is installed directly in `Backdrop` as a moving background layer, not displayed as a static screenshot. The source reference was generated for this project. Edge alpha fades prevent obvious vertical clipping. It is still an interim production asset and should ultimately be superseded by an original standalone painted background designed for seamless repeating.
