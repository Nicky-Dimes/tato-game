# Controls

| Action | Keyboard | Gamepad | Touch |
|---|---|---|---|
| Move | A / D or ← / → | left stick or D-pad | Move buttons (bottom left) |
| Jump / flap / glide | Space or Z | A | Jump button |
| Attack (honk or power) | J or X | X or B | Attack button |
| Crouch / belly-slide / drop through | S or ↓ | stick down | slide the moving thumb down |
| Talk / go in (Home Nest) | W or ↑ (or Attack) | stick up | Attack button (shows GO) |
| Pause | Esc or P | Start | pause button (top right) |

Everything can be remapped in **Settings → Controls**. Touch buttons appear by
themselves on phones and tablets; their size and visibility are in **Settings → Comfort**.
