# Original handoff package (2026-11-10, v0.1)

These are the documents the project started from. They describe an earlier design
(two Flavor Pockets, fusion recipes, puzzle creatures). On the same day the owner
replaced that design with the five boards in `assets/reference/*_sheet.png`
("one active attack power", hearts, 18 enemies, six new bosses, six re-themed worlds).

Where these documents and the boards disagree, **the boards win**. What is still in
force from here: the two-wings / two-feet rule for Tato, the technical choices
(Godot 4.7 GDScript, Compatibility renderer, single-threaded web build, JSON saves with
backup and migration), accessibility options, and the release checklist.

The game as built is described in `docs/GAME_DESIGN.md`.
